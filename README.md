# Personal Portfolio Landing Page

Multilingual personal landing page for Narek.

This repository is the GitHub Pages home for the portfolio and should become the public landing page that connects the strongest GitHub projects, technical positioning, and contact links.

## Purpose

The goal of this site is to present Narek as a practical technical builder focused on:

- AI automation
- IoT and monitoring systems
- internal business tools
- Telegram integrations
- dashboards and small CRMs
- real-world workflow automation

## Languages

- English
- Russian
- Armenian

## Suggested site structure

```text
Hero section
   ↓
Short positioning statement
   ↓
Featured projects
   ↓
Skills / stack
   ↓
Business and IoT case studies
   ↓
Contact links
```

## Files

- `index.html`
- `styles.css`
- `script.js`

## Run locally

Open `index.html` in a browser.

Or serve it locally:

```bash
python3 -m http.server
```

Then open:

```text
http://localhost:8000/business-card-site/
```
