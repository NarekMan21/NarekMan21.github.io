# business-card-site

Multilingual personal landing page for Narek.

## Languages
- English
- Russian
- Armenian

## Files
- `index.html`
- `styles.css`
- `script.js`

## Run locally
Open `index.html` in a browser.

Or serve it:

```bash
python3 -m http.server
```

Then open:
- `http://localhost:8000/business-card-site/`
